# Mixxx PR Analyzer

A GitHub App that automatically analyzes PRs for the Mixxx DJ project using Google Gemini (free tier).

## Features
- 🔍 Detects signs of AI-generated code
- 📝 Generates thoughtful review questions
- 🎯 Evaluates code quality
- ⚡️ 100% free (uses Gemini free tier)

## Setup
1. Add your Gemini API key to Render environment variables
2. Configure GitHub App webhook
3. Install on Mixxx repository
